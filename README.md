# HD2 Integrated Armor System

HD2 综合护甲系统的版本更新仓库。

当前版本：**1.4.4**

安装包发布在 [Releases](https://github.com/Estecsky/HD2-Integrated-Armor-System/releases)

V1.4.0更新公告

经过26个测试版和内测组每天都高强度测试，我们终于搬出了史诗级优化的1.4版本

当然，内测组也没法完全测试到所有情况，如果有遇到严重bug，还请上报让我们修复

更新内容：
-（核心）添加了 Lua 和原生双路线，以及独立的部署和 data 包生成入口。
-（核心）添加了关闭队友护甲系统的功能，现在多人情况下在关闭队友系统后可以畅玩，同环境帧数与单人相差不大
-（核心）删除了幻化支持，现在幻化系统的调用不再需要体积巨大的幻化包了
-（核心）优化了系统静态下的显存占用，原来约2-3g的静态显存占用现在几乎归零
- 添加了五档队友刷新速度调节。
- 添加了 Mod Dynamic Loader识别支持。
- 优化了 data 包体积
- 优化了系统检查提示和故障处理指引。
- 修复了部分老 Mod 导致 data 包生成失败的问题。
- 修复了队友身体和头盔混搭时的开关恢复问题。
- 修复了切换头盔幻化时身体反复恢复的问题。
- 修复了老 Mod 幻化和隐藏护甲配件 Mod 引起的恢复阻断。
- 修复了队友外观恢复时的额外等待。
- 修复了卸载系统时个人设置、预设和原 ReShade 字体的保留与恢复问题。

如果遇到以下问题不视为bug，均为刻意/为了实现目的所设置或暂无修复方法：
- 关队友刷新较慢
- 关队友后在刷新前无独立骨
- 关队友后空投仓内队友依旧生效独立骨
- 队友加入/复活时轻微掉帧
- 偶尔遇到独立骨失效
- 部分mod冲突导致系统失效
- 军械库/空投仓较卡（仍在研究优化）

如果有其他bug或问题则欢迎上报
