## HD2 综合护甲系统 1.6.4 更新日志

【此版本为旧路线的最终功能更新版本，优化已接近极限，后续当前路线只会再修复小bug，大部分精力将推进研发不依赖任何外接与注入的纯patch IAS路线】

### 动作与性能

- 核心性能优化更新：在 F4 面板的「综合优化」中，可以把自身第三人称姿态修正频率调到 15–60 Hz，默认 30 Hz+运动插帧。局内调整即时生效并自动保存。这个数值表示每秒修正姿态的次数，游戏本身可以超过 60 FPS。
- 修正频率越高，动作越流畅，游戏帧率可能越低。调低修正频率可以减轻 CPU 负担、提高游戏帧率，但走路和挂件摆动可能略有卡顿。开启「运动插帧」可以缓解这种卡顿。默认设置下30帧修正加开启插帧可以让幻化帧数损失降到10帧左右
- 运动插帧覆盖步态和 Mod 自定义物理。头发、饰品等挂件在两次物理修正之间最多补三个中间姿态。优化了骨骼的重复读取、写入和部件刷新，静止部件会跳过多余的更新。
- 队友默认使用原有外观。在角色库为队友指定 Mod 后，该队友的姿态按 20 Hz 修正，队友运动插帧可以单独开关。

### 面板与图形组件

- 彻底剥离了系统与reshade的联系。F4 使用游戏原生面板。幻化、预设和姿态修正可以独立运行。需要 DLSS 组件或隐藏披风时，可在客户端的「DLSS 管理」页选装 ReShade。
- 修复了部分新护甲导入时缺少资源的问题，并改进了 ReShade 在 DX11 多设备环境下的兼容性。
- 修复设置保存失败。当前用户配置目录拒绝写入时，设置会自动保存到该用户的备用目录。安装器自动补齐组件证书，工具页保留手动安装入口。
- 修复空配置导致设置无法保存的问题，优先恢复已有的旧配置。选择文件夹支持管理员模式；系统对话框出错时可以直接输入路径。组件解压遇到临时目录拒绝访问时会自动改用客户端的临时目录。

### 升级说明

- 使用 MDL3 前置，系统 data 包继续手动导入
- 安装时自动安装证书（因此会申请UAC）
