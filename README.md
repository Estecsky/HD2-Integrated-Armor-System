# HD2 Integrated Armor System

HD2 综合护甲系统的版本更新仓库。

当前版本：**1.6.0**

安装包发布在 [Releases](https://github.com/Estecsky/HD2-Integrated-Armor-System/releases)

1.6.0 更新日志

经过十几天的不断修复，二十多个测试版的测试以及广大内测群友的努力，系统终于能在新版本下正常工作了
目前大的BUG基本都修复完毕，若还遇到少部分BUG，请及时汇报

新版本安装：完整删除原系统后，在潜兵同盘的其他地方新建一个干净文件夹，安装存放新系统

如果安装没问题，自检也正确，但是就是不生效，请以管理员权限启动客户端后去工具那里安装证书

更新内容：
- EAC版本更新后修复，现在可以正常使用了
- 添加了四名队员独立角色库，身体和头盔可分别选择 Mod 外观或原版幻化。
- 添加了 Mod 图标显示和护甲面板快捷键设置。
- 添加了系统与 Mod 配套的独立部署。
- 添加了 DLSS 管理，帧生成与 DLSS5 神经渲染二选一部署，分别保留设置。
- 添加了帧生成倍率、DLSS 超分辨率、输出帧率显示和 DLSS5 工作分辨率调节。
- 添加了内置的reshade隐藏披风和隐藏民主官头部功能，默认仅开启隐藏披风。
- 添加了前置、data、护甲和 DLSS 组件的统一自检。
- 修复了游戏更新后护甲幻化和 Mod 配套生成失效的问题。

进入游戏后，默认显示原甲，打开reshade面板或者直接按F4即可打开护甲面板更换护甲
军械库、空投仓均统一显示原甲
当前reshade仅为系统自用，功能有限，如果想要制作额外功能适配，请联系我
