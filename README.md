# HD2 Integrated Armor System

HD2 综合护甲系统的版本更新仓库。

当前版本：**1.4.4**

安装包发布在 [Releases](https://github.com/Estecsky/HD2-Integrated-Armor-System/releases)；[1.4.0／1.4.1／1.4.2／1.4.3 → 1.4.4 离线更新包](https://github.com/Estecsky/HD2-Integrated-Armor-System/releases/download/V1.4.4/HD2IAS-1.4.4-offline-update.zip)。客户端通过签名更新清单检查可用更新。

1.4.4 合入原生 H6 修复，解决队友加入或返回舰船后偶发还原不完成的问题。资源查询短暂不可用时会等待并继续分段恢复，避免重复提交已完成的操作。保留 1.4.3 头盔差分和 S1 护甲拉伸修复。

原生路线用户更新后请退出游戏，在“安装系统”页重新部署成对的原生宿主和 addon。已使用 1.4.3 的 Lua 路线仅需更新客户端；1.4.0–1.4.2 用户仍需退出游戏并重新部署所选路线，才能包含头盔差分修复。

沿用原路线时无需重新生成系统 data 包；切换路线时请按既有流程重新生成并在 Arsenal 替换，只保留一份系统 Lua。

原先缺少差分清单的组差分模型包，需要作者使用修复后的 SDK 重新导出模型和配套运行时包。本次运行时安装器不包含 Blender 插件。

更新请在客户端更新页中拉取更新。

1.3.x 及更早版本请使用最新完整安装器；1.4.0、1.4.1、1.4.2、1.4.3 可通过客户端在线更新或离线包升级。使用完整安装器时，请先卸载原来的护甲系统，再安装本版。

V1.4.0更新公告

经过26个测试版和内测组每天都高强度测试，我们终于搬出了史诗级优化的1.4版本

当然，内测组也没法完全测试到所有情况，如果有遇到严重bug，还请上报让我们修复

更新内容：
-（核心）添加了 Lua 和原生双路线，以及独立的部署和 data 包生成入口。
-（核心）添加了关闭队友护甲系统的功能，现在多人情况下在关闭队友系统后可以畅玩，同环境帧数与单人相差不大
-（核心）删除了幻化支持，现在幻化系统的调用不再需要体积巨大的幻化包了
-（核心）优化了系统静态下的显存占用，原来约2-3g的静态显存占用现在几乎归零
- 添加了五档队友刷新速度调节。
- 添加了 Mod Dynamic Loader识别支持。
- 优化了 data 包体积
- 优化了系统检查提示和故障处理指引。
- 修复了部分老 Mod 导致 data 包生成失败的问题。
- 修复了队友身体和头盔混搭时的开关恢复问题。
- 修复了切换头盔幻化时身体反复恢复的问题。
- 修复了老 Mod 幻化和隐藏护甲配件 Mod 引起的恢复阻断。
- 修复了队友外观恢复时的额外等待。
- 修复了卸载系统时个人设置、预设和原 ReShade 字体的保留与恢复问题。

如果遇到以下问题不视为bug，均为刻意/为了实现目的所设置或暂无修复方法：
- 关队友刷新较慢
- 关队友后在刷新前无独立骨
- 关队友后空投仓内队友依旧生效独立骨
- 队友加入/复活时轻微掉帧
- 偶尔遇到独立骨失效
- 部分mod冲突导致系统失效
- 军械库/空投仓较卡（仍在研究优化）

如果有其他bug或问题则欢迎上报
